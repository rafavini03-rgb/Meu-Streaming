# Meu Streaming

**Aplicativo pessoal de streaming para Windows e Android.**

O Meu Streaming é um projeto desenvolvido em Flutter para organizar e reproduzir uma biblioteca pessoal de filmes, séries e animes.

## Funcionalidades

- Integração com Google Drive.
- Reprodução de arquivos de vídeo locais e na nuvem.
- Biblioteca visual com interface cinematográfica.
- Organização de filmes, séries e animes.
- Favoritos e histórico individual por conta.
- Identificação automática de títulos e capas por meio do TMDB (em desenvolvimento).

## Plataformas

- Windows
- Android

## Tecnologias

- Flutter / Dart
- Google Drive API
- TMDB API
